# handoff/

A relay baton for whoever continues the AWDAX app build: Claude, ChatGPT Astra, Codex or a person.
The files stay current at every commit, so work can stop at any point and be picked up here.

| File | Read it for |
|---|---|
| `CONTINUE_PROMPT.md` | The prompt to paste into the next agent. Start here. |
| `HANDOFF.md` | Current state, how to run everything, rules, decisions, gotchas |
| `TASKS.md` | The milestone checklist: what's done, what's next, the exact next step |
| `PLAN.md` | The approved plan, frozen as the owner approved it on 2026-09-27 |

Whoever works on the app updates `HANDOFF.md` and `TASKS.md` in the same commit as the code.
